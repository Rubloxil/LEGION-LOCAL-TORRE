# 📚 Entregables SENA - Evidencias de Formación

## Descripción

Este repositorio contiene las actividades, ejercicios, evidencias y entregables desarrollados durante las sesiones de formación correspondientes a la semana académica.

Cada carpeta representa una clase o sesión de formación diferente, por lo que se recomienda revisar la carpeta correspondiente para consultar las actividades y evidencias desarrolladas en cada tema.

---

## Instrucciones para la Revisión

Para una correcta validación de los entregables:

1. Ingrese a la carpeta correspondiente a la clase que desea revisar.
2. Verifique los archivos asociados a dicha sesión de formación.
3. Consulte la documentación y evidencias almacenadas en cada directorio.
4. Revise los avances realizados según las instrucciones suministradas durante la formación.

---

## Objetivo del Repositorio

Centralizar y organizar todas las evidencias de aprendizaje desarrolladas durante la semana de formación, facilitando el seguimiento, revisión y evaluación de las actividades realizadas.

---

## Observaciones

* Cada carpeta corresponde a una clase diferente.
* Los archivos fueron desarrollados de acuerdo con las guías y actividades propuestas.
* La organización del repositorio busca facilitar la navegación y revisión de las evidencias.
* Se recomienda revisar cada carpeta individualmente para identificar el contenido correspondiente a cada sesión.
