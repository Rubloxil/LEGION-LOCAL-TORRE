# 📚 Mini Proyecto Biblioteca - Docker y PostgreSQL

## 📖 Descripción

Este proyecto consiste en el desarrollo de una base de datos para la gestión de una biblioteca utilizando PostgreSQL como sistema gestor de bases de datos y Docker para la creación y administración del entorno de ejecución.

El proyecto permite registrar libros, autores, usuarios y préstamos, aplicando conceptos fundamentales de bases de datos relacionales, consultas SQL y contenedores Docker.
